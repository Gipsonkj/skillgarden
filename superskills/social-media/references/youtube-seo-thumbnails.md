# YouTube: titles, descriptions, chapters, thumbnails

Use this for YouTube SEO, video titles and descriptions, tags, chapters, thumbnails and covers, Shorts metadata, and video series. Uploading through the API is in publishing-apis.md.

YouTube is the second-largest search engine, its videos appear in Google results, and it is among the most cited social sources in AI answers. Title, thumbnail and description work as one system: they must promise the same thing.

## 1. Intake

Video type (tutorial, review, vlog, interview, Short), one primary keyword and 1-2 secondary ones, audience (subscribers vs search viewers), and the one true promise the video delivers.

Find the keyword by typing candidate phrases into YouTube search (autocomplete), checking the titles and view counts of the top results, and preferring phrases where small channels still rank.

## 2. Titles

| Rule | Detail |
|---|---|
| Length | Max 100 characters; keep it under ~60 so it is not cut off on mobile |
| Keyword | Primary keyword inside the first ~50 characters, phrased the way people search |
| Shape | Outcome or curiosity + keyword ("I Tried 5 Budget Mics: One Beat a $400 Shure") |
| Style | Conversational; no keyword stuffing; ALL CAPS on one word at most |
| Truth | The video must deliver what the title promises in the first minute |

Write 5 options; pick the one that pairs best with the thumbnail (do not repeat the thumbnail text in the title; extend it).

## 3. Description

- **First 100-160 characters:** a plain summary containing the primary and a secondary keyword; this is what search shows.
- Then 2-4 short paragraphs on what the viewer will learn, links (site, product, related videos, playlist), and credits.
- **Chapters:** timestamps starting at `0:00`, at least 3 chapters, each at least 10 seconds, with keyword-bearing names.
- Limit: 5,000 **bytes** (non-Latin scripts use it up faster).
- **Hashtags:** 3-5; the first 3 show above the title; more than 15 makes YouTube ignore all of them.

## 4. Tags

Tags matter far less than title, description and thumbnail. Add 5-15 relevant ones (exact keyword, variants, common misspellings, channel name); total tag text max 500 characters.

## 5. Thumbnails

Specs: 1280x720 (16:9), under 2 MB, JPG/PNG. Shorts covers 1080x1920 with faces in the upper two-thirds; Instagram covers 4:5.

Rules that hold across sources:
- **One focal subject**, filling roughly 40-60% of the frame; minimal clutter.
- **An information gap:** the image raises a question the video answers.
- **Readable at ~120 px wide** (the size most viewers see it); test by shrinking it.
- High contrast, bold colour, clear subject/background separation; a face with a strong, real emotion if a person appears.
- Text optional; if used, 2-4 words that extend the title, never repeat it, never covering the face.
- **Truthful:** exaggerate presentation, never the facts. A misleading thumbnail kills retention and trust.
- Keep a consistent visual system for a series so it is recognizable in suggested videos.

Concept frameworks (brainstorm at least 5 options across several, then pick the strongest gap):

| Framework | Idea |
|---|---|
| Portrait | Large subject, strong emotion, almost empty background (the default) |
| Action moment | One intriguing action caught mid-way |
| Before/after | Two states of one subject, split frame |
| Three-step progression | Start, middle, end in three panels |
| Product as answer | The product is the hero and the answer to the title's question |
| Size contrast | Giant vs tiny element central to the story |
| Quantity | Many of one object, plus a person for scale |
| Map / aerial | A highlighted route or point |
| Simple chart | A familiar graph shape (bell curve, spike) |
| Day marker | A big "DAY N" badge late in a challenge arc |
| Generic chat/review card | A short, true message bubble next to the subject (no real platform logos) |
| Real frame | A strong frame from the video itself |

Production:
- Generate or design with whatever image tool the user has (an image model, Canva, Figma, a photo plus cut-out). Keep generated images **text-free** and add text as a separate, deterministic overlay so spelling is exact.
- Never copy another creator's thumbnail identity or exact composition; references are for mood and layout only.
- Do not depict real people without their consent, and do not invent screenshots, stats or results.
- Deliver 3-4 variants with short labels (e.g. "shock / close-up", "product / size contrast") and let the user choose. YouTube's built-in "Test & Compare" can A/B up to 3 thumbnails on a live video.

## 6. Shorts

Searchable title (the keyword, not "#shorts" alone), 1-5 hashtags, a 1-2 second hook, burned-in captions, and a link to the related long video. See short-form-video.md for scripting.

## 7. Series and playlists

- Bundle parts in a playlist; link it above the description fold on every part.
- Title parts "[Series] - Part X: [specific topic]"; end screen to the next part.
- Mention earlier parts in the first 30 seconds and the next part in the last 30.
- Use Community posts between uploads (polls, "what should Part 3 cover?").

## 8. Checklist

- [ ] Keyword in title (first ~50 chars) and in the first 160 chars of the description
- [ ] Title under ~60 chars and truthful; thumbnail extends it rather than repeating it
- [ ] Thumbnail readable at 120 px, one focal subject, real promise
- [ ] Chapters from 0:00, 3+ entries
- [ ] 3-5 hashtags; tags under 500 chars
- [ ] Playlist and end screen set for series
