# Repurposing: one piece into many formats

> Distilled from: content-engine (affaan-m/ECC, MIT), content-repurposer-sms (blacktwist/social-media-skills, MIT), content-strategy distribution reference (coreyhaines31/marketingskills, MIT).

Use for "repurpose", "turn this into", "adapt this for", "blog to thread", "newsletter to posts", "podcast/video to clips", "cross-post", "get more from this content". This file covers the writing of derivatives. Scheduling, posting, hashtag strategy and platform analytics belong to the social-media super skill.

## Principle: create once, distribute twice

One strong flagship, cut into platform-native pieces, beats many thin posts made from scratch. Plan the cuts while writing the flagship: subheads that work as standalone posts, sections that lift out cleanly, quotes and stats pre-picked for graphics.

Route attention from **borrowed** (podcasts, guest posts, partners) and **rented** (social feeds) toward **owned** (email list, blog, community). Every derivative should point somewhere you own.

## The process

1. **Pick the anchor asset** and summarize its core argument in one sentence.
2. **Extract 3-7 atomic insights.** Each must stand alone without the source. For each: the claim in one sentence, its proof (number, example, story beat), who it is most useful for. Label the type: stat, story, framework, how-to, contrarian claim, quote.
3. **Rank** by sharpness, novelty and proof. Test: "If someone saw only this post, would it be worth their time?" Reframe or merge the ones that fail.
4. **Assign one idea per output.** Never cram three insights into one post.
5. **Match insight to format:**

| Insight type | Best format |
|---|---|
| Step-by-step process | Carousel or thread |
| Single counterintuitive claim | Standalone post or thread opener |
| Story with a lesson | Thread or long LinkedIn post |
| Data point | Standalone post with its context |
| Framework or model | Carousel, one slide per part |
| Memorable line | Quote post or graphic |

6. **Draft each derivative natively.** Adapt format and register to the platform; keep the author's voice (load the VOICE PROFILE or TONE.md from [brand-voice.md](brand-voice.md)).
7. **Strip platform filler** and run [humanize-ai-writing.md](humanize-ai-writing.md).
8. **Quality gate** (below), then rank by leverage and propose an order.

## Source → derivatives map

| Source | Best derivatives | Visual asset needed |
|---|---|---|
| Blog post | LinkedIn post (key insight), X thread (takeaways), carousel (framework), 3-5 standalone posts, newsletter section, Pinterest pins per section | Carousel slides, pin graphics |
| Newsletter | Thread expanding the main argument, the one-sentence post, carousel, archive pin | Slides |
| Podcast / video transcript | 3 quote posts, thread of key moments, carousel of insights, 30-90 s vertical clips, recap blog post | Vertical clips, audiogram |
| Case study | Narrative thread, long LinkedIn post, before/after carousel, story-time short video | Slides, vertical video |
| How-to | Step carousel, one-step-per-post series, demo shorts, multi-page pin | Step graphics, demo footage |
| Long YouTube video | 3-7 shorts, takeaway thread, LinkedIn post linking the video, transcript-based blog post | Vertical re-cuts |
| Webinar | Replay, podcast audio, blog recap, slide carousel, clips | Replay, slides, clips |

## Platform writing rules (text only)

| Platform | Length and shape | Register |
|---|---|---|
| X | under 280 chars per post; strongest claim or artifact first; threads: each post advances the argument | sharp, compressed |
| LinkedIn | 3-5 short paragraphs; hook in the first ~2 lines before "see more" (~1,300 chars is a common sweet spot); link in first comment | thoughtful, story-forward; no "journey" or praise-stacking |
| Threads | short, casual | low-key |
| Bluesky | 300-char limit, little hashtag culture | dry, anti-corporate |
| Facebook | 40-500 chars, story-led, links work in body | personal, community |
| Instagram | hook in first 125 chars; 200-800 char caption; link in bio | caption supports the image |
| TikTok / Shorts / Reels | caption under ~150 chars; script shows the result or problem in the first seconds | native, low-polish |
| Pinterest | title ≤100 chars keyword-led, description ≤500 chars | helpful, search-led |
| YouTube long | title 60-70 chars, chapters, links above the fold | educational, hook then payoff |
| Newsletter | open with the point; see [newsletters.md](newsletters.md) | personal |

Short video scripts: write around the visual sequence and the proof points; narration that reads well on paper often sounds wrong spoken.

## Platform half-lives (match effort to shelf life)

| Channel | Rough half-life |
|---|---|
| X post | minutes to hours |
| Instagram / Facebook / LinkedIn | about a day (strong LinkedIn posts longer) |
| TikTok / Reels / Shorts | days to weeks (resurfacing) |
| YouTube | months to years |
| Blog / SEO | years |

Short-lived channels reward repetition; long-lived ones reward depth.

## Leverage ranking (default; adjust to the user's platforms)

1. Vertical clip from a video moment (one asset, three platforms)
2. X thread
3. LinkedIn post
4. Carousel (saves resurface for weeks)
5. Long YouTube video
6. Pinterest pin (6-12 month tail)
7. Threads post, Facebook post, quote posts

## Anti-patterns

- Identical text on every platform.
- "I wrote a blog post about..." as the post. Write the insight natively.
- Everything posted the same day. Spread over 5-7 days, about 24 h apart, anchor first.
- Blog bullet lists pasted into casual platforms.
- "Great insights in this post!" with no actual insight.
- Engagement bait ("Agree?", "Thoughts?") or a closing question added just to farm replies. A real question with a trade-off is fine.
- New claims that are not in the source. A derivative may compress, never invent.

## Quality gate

- [ ] Each draft carries one real claim, proof point or observation from the source
- [ ] Sounds like the author, not the platform stereotype
- [ ] No duplicated copy across platforms unless asked
- [ ] Within the platform's length limit
- [ ] No hype words, no bait; any CTA is earned and approved

## Deliverable

```
Source summary: one sentence
Core angle: ...
Derivatives: per platform → format, full draft, notes (e.g. "post as reply chain")
Leverage ranking: list with one-line reason each
Suggested order: Day 1 anchor ... Day 5-7
Gaps to fill before publishing: [NEED: ...]
```
