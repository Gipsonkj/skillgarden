How the garden grows

Nothing reaches a super skill without being found, ranked, distilled and approved first.

  1. Scout

    Every Sunday a scout looks for new public skills, one craft at a time, on GitHub, in skill lists and in expert picks.

  2. Rank

    Each find is ranked by stars, installs and expert lists, and its licence is checked. Non-commercial skills stay link-only.

  3. Distil

    The best techniques become short guides behind one router per craft. A change goes in only after it is reviewed and approved.

  4. Harvest

    You install one super skill. Ask in plain words and Claude opens only the guide your task needs.

Bring it to Claude

Use the plugin in Claude Code, or upload super skills to claude.ai one craft at a time.

Claude Code: all {{CRAFTS}} as a plugin

Run these two commands in a terminal. Every super skill and chain then loads in every session.

claude plugin marketplace add Gipsonkj/skillgarden
claude plugin install skillgarden@skillgarden

Then ask normally, for example "animate this modal so it feels snappy". To pick up new versions, run claude plugin marketplace update skillgarden.

claude.ai and the Claude apps

  1. Open a craft in the garden and press Download.
  2. In claude.ai, go to Settings, then Capabilities, then Skills.
  3. Upload the zip and turn it on.

Want them all? The garden has a "Download all super skills" button.
