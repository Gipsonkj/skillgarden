# Composition rules — the taste layer

Nothing here needs a library. This is what separates a designed page from a generated one.
Sourced from three reels (a graphic-design fix reel, a photography pairing reel in Spanish, a
design pairing reel) plus the "Aesthetic List" card.

---

## 1. The four diagnostic fixes

From `@_tanupriya_` / allthingsdesign.co. Each demonstrated as a real before→after on a poster.
Read the symptom, apply the move. These are ordered by how often they're the actual problem.

### "It looks boring" → **Adjust the layout**
*Demo: a "BANANA" poster.* Before — a single centred image with a caption underneath. After —
the composition re-cut so the elements sit in a deliberate asymmetric relationship.
The default centred vertical stack is what every generated page produces. Breaking the grid is
usually the whole fix.

### "It doesn't stand out" → **Exaggerate the scale**
*Demo: "BAG CULTURE".* Before — modest type over a product shot. After — the wordmark blown up
far past comfortable, cropping and bleeding off the frame.
Scale contrast is the cheapest hierarchy. One element must be *unreasonably* large.

### "It looks plain" → **Add more details**
*Demo: "La Dolce Vita".* Before — clean type on a plain field. After — ornamental border,
secondary marks, texture, small annotation type.
"Clean" and "empty" are different things. Detail is what makes a surface read as considered.

### "No focus point" → **Use contrast**
*Demo: "RAMEN JAPAN" card.* Before — everything in one blue. After — the identical layout with
the key element flipped to red.
Contrast can be colour, weight, size or temperature. One thing wins; everything else defers.

## 2. The pairing law

**One aesthetic reads as *fine*. Two stacked read as *intentional*.**

This appeared independently in two reels — one about photography, one about graphic design —
with the same grammar every time: *X alone is good, Y alone is good, **together** they are
<the actual result>*. Ship two treatments, never one.

### Photographic pairings
| Pair | Result |
|---|---|
| Black & white + colour pops | **iconic** |
| Blur + grain | **more interesting** |
| Vintage photo + modern typography | **timeless** |
| Low exposure + candlelight | **intimate** |

### Graphic pairings
| Pair | Result |
|---|---|
| Text + portraits | **cool** |
| Crossword / print artifact + photo | **nostalgic** |
| Animals + colour | **eye-catching** |
| Envelope / paper object + photo | **lovely** |

**How to use this on a website:** pick two and commit — e.g. *desaturated photography + one
saturated accent*, or *archival texture + contemporary grotesque*. A page running one treatment
looks like a template. A page running three looks like a mess.

## 3. The Aesthetic List

Ten levers for reading or building a composition. Use them two ways: to *diagnose* ("this hero
has no tension") and to *brief* ("build this section on isolation and negative space").

1. **The Accent** — one element carrying all the visual interest
2. **Isolation** — a subject separated from everything around it
3. **Grouping** — repeated elements read as one object
4. **Framing** — using foreground geometry to enclose the subject
5. **Negative Space** — emptiness as the active element
6. **Golden Ratio** — proportional placement
7. **Movement** — implied direction through the frame
8. **A Diptych** — two frames that mean something only together *(see the pairing law)*
9. **Tension** — imbalance held deliberately, not resolved
10. **Symmetry** — deliberate mirroring

---

## 4. Applying this to a web page

- Run the four fixes as a checklist on any section that "feels off" **before** touching code.
- Every page should be able to name **two** paired treatments and **one or two** aesthetic-list
  levers. If it can't, it has no design read — that's the actual defect.
- The hero almost always needs *exaggerate the scale*; interior sections almost always need
  *use contrast*; a page that reads as sterile needs *add more details*, not more whitespace.
